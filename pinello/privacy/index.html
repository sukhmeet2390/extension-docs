2. What This Extension Does

Pinello helps Pinterest creators prepare stronger Pins before publishing. It surfaces a Feed Score on Pin cards while you browse, a Pin Detail Score inside the Pin closeup, and a Pin Doctor pre-publish check inside the Create Pin workflow. Structural scoring runs locally in your browser. AI suggestions and Board Match run only when you explicitly click the corresponding button.

4. What Leaves Your Browser

While you browse Pinterest and while the Pin Doctor scores your draft locally, no Pin content leaves your browser.

Data is sent to our backend only when you click one of the following actions:

ActionWhat is sentWhere it goes
Suggest a stronger title / description / topicsAnonymous device ID, the draft title / description / topics, the selected board name (for context), extension versionOur Azure backend, which forwards to Azure OpenAI (Microsoft) for a single AI call
Check board matchAnonymous device ID, the draft Pin text, the selected board name, extension versionOur Azure backend, which forwards to Azure OpenAI embeddings for a similarity score
Anonymous analytics eventsAnonymous device ID, event name (for example doctor_opened, ai_action_completed), extension version, browser locale. No Pin content.PostHog (product analytics)

Image analysis is 100% local. The extension reads pixels from Pinterest CDN images via the browser Canvas API to check aspect ratio, resolution, and text overlay density. Pixel data is discarded immediately and never uploaded.

Pinello never types into Pinterest for you. AI suggestions are copy-only: they land on your clipboard for you to paste.

All backend transmission uses HTTPS / TLS 1.3.

5. Backend Caches

Our backend caches limited data to avoid double-charging you for repeated actions and to keep the service fast:

  • AI suggestion cache: generated alternative title / description / topics text, keyed by a hash of the input. Retained for approximately 24 hours.
  • Board Match cache: similarity score for a given (Pin text, board name) pair, keyed by a hash of the input. Retained for approximately 30 days.
  • Fair-use usage records: anonymous device ID plus per-action counters used to enforce Free-tier limits and Pro fair-use caps. Retained for approximately 32 days.

Caches are keyed by anonymous device ID and content hash only. They are not sold, shared with third parties, or used for advertising.

6. What We Do NOT Collect

  • Your Pinterest account credentials, session tokens, or login information
  • Pin images (all image analysis is local and pixel data is discarded)
  • Browsing history or activity outside of pinterest.com and pinimg.com
  • Your name, email, or other personally identifiable information — unless you email us for support
  • Payment card details (handled by Stripe via ExtensionPay; we never see card data)

9. Data Retention Summary

  • Local score history: cleared on browser restart; you can clear at any time in Options.
  • Local preferences and device ID: retained until you clear extension storage or uninstall.
  • Backend AI suggestion cache: approximately 24 hours.
  • Backend Board Match cache: approximately 30 days.
  • Backend fair-use usage records: approximately 32 days.
  • PostHog anonymous events: retained per PostHog defaults; deletion available on request.
  • Sentry error logs: 90 days.

10. Children’s Privacy

Pinello is not intended for users under 13 (COPPA) or under 16 in the EU (GDPR). We do not knowingly collect data from children.

11. Security

  • All data in transit: HTTPS / TLS 1.3
  • Backend secrets held in Azure Key Vault; no API keys or secrets are shipped inside the extension
  • Per-user and global spend caps prevent abuse of the AI backend
  • Suggestions and Board Match are AI features and can hallucinate — you are responsible for reviewing text before publishing

12. AI Disclosure

Pinello uses AI (currently GPT-4.1-mini and text-embedding-3-small via Azure OpenAI) to generate title / description / topics suggestions and to score Board Match. AI is invoked only when you click a suggestion or Board Match button. AI outputs are labelled in the interface, are copy-only (never auto-inserted), and are not guaranteed to improve Pinterest performance.

13. Changes to This Policy
